# Luca LiVigni Personal Website

A personal portfolio website built to showcase my projects, skills, and interests in technology, AI, and software. 

## Live Site

[Open the website](https://personal-website-kappa-smoky-86.vercel.app/)

## Overview

This website serves as my personal portfolio and a central place to share the projects I am building. It highlights my technical interests, selected projects, skills, and ways to connect with me.

## Features

- Responsive personal portfolio layout
- Animated orbital hero section
- Project cards with GitHub and live demo links
- Skills section focused on programming, data, machine learning, and software tools
- About and contact sections
- Clean dark theme with emerald accents

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js / React Three Fiber

## Featured Project

### Los Angeles Airbnb Price Predictor

An end-to-end machine learning project that predicts Airbnb nightly prices using listing details, location, and market factors. The project includes a deployed dashboard, model comparison, PySpark analysis, and MLflow experiment tracking.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/LucaLiVigni27/personal-website.git
cd personal-website
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the local site:

```text
http://localhost:3000
```

## Build

To create a production build:

```bash
npm run build
```
